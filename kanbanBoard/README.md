# Trackly

Trackly is a simple, dark-themed task board for organizing work across three stages: **Todo**, **Progress**, and **Completed**. Add tasks, drag them between columns, or delete them. Dropping a task outside a column leaves it in its original place.

## Built with

- React
- JavaScript
- CSS
- Vite

Task movement uses the browser's built-in drag-and-drop API; no additional libraries are required.

## Run locally

From the project directory:

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. To create a production build, run `npm run build`. To check the code with ESLint, run `npm run lint`.
